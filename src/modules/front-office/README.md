# Front Office Module

Folder ini berisi halaman dan logika front office: registrasi pasien, pencarian data pemilik/hewan, kirim pasien ke dokter, rawat inap, data selesai, dan integrasi anamnesis awal dari FO.

Nanti ketika sudah masuk database, fungsi yang sekarang membaca/menulis localStorage bisa diarahkan ke API PHP melalui `fetch('/api/...')`.
